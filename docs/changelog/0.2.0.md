# dsh-continue v0.2.0

Date: 2026-08-24

本版本让继续操作支持持久化配置, 并与 DSH 发送按钮和设置界面保持一致.

## Highlights

- 可配置继续消息, 重启或重新加载后仍然保留.
- 继续操作与 DSH 原生发送按钮保持一致的设置和交互位置.

## Features

- 设置 > 通用中提供继续消息配置项.
- 输入框为空时可直接发送配置的继续消息.
- Agent 工作期间隐藏继续按钮, 避免重复提交.

## Upgrade Notes

1. 更新插件后重新加载 DSH plugin.
2. 打开设置 > 通用, 检查继续消息配置.
3. 在输入框为空时点击继续按钮, 验证配置消息可以发送.
